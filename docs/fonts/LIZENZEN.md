# Schriften und ihre Lizenzen

Alle Schriften stammen von Google Fonts und werden lokal ausgeliefert (keine Anfragen an fremde Server).
Sie stehen unter freien Lizenzen; der vollständige Lizenztext jeder Familie liegt im Ordner `lizenzen/`.
